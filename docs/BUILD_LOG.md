## החלטות שננעלו
- בקר: **ESP32 DevKit V1** (במקום Arduino Nano מההצעה המקורית).
- מצלמה: לפי רשימת הציוד — **Stereo Dual-Lens** (מניחים שקיים).
- תקשורת PC↔ESP32: **USB-Serial @115200** (ברירת מחדל; ESP32 תומך גם WiFi כגיבוי).

## פתוחים / לבדוק
- ✅ נפתר: OpenCV עובד על Python 3.14 (wheel cp37-abi3) — לא נדרש venv נפרד.
- ספק 5V חיצוני (~2A) לשני מנועים בו-זמנית — לרכוש/לאמת.
- מצלמת USB שחור-לבן — לחבר ולמצוא אינדקס.
